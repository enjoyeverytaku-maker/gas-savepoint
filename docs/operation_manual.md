# SavePoint 操作マニュアル

対象読者: SavePointを実際に使う方（エンジニアでない方も含む）。開発・デプロイ手順は `README.md` を参照してください。

最終更新: 2026-09-15

---

## 1. SavePointとは

社内で使っているGoogle Apps Script（GAS）の「いつ・何が変わったか」を記録し、必要なら過去の状態に戻せるようにするツールです。

GASはスプレッドシートやフォームと連携した業務ツールとしてよく使われますが、標準の状態では「誰が」「いつ」「何を」変更したかの記録が残らず、動かなくなったときに元に戻す手段もありません。SavePointは、GASのエディタで直接編集した内容を後から検知し、「セーブポイント」として記録し、必要なときにワンクリックで過去の状態へ復元できるようにします。

**重要**: GAS本体のコードは、GASエディタで保存した瞬間に本番へ反映されます（トリガーやWebhookもその瞬間から新しい内容で動きます）。SavePointは「反映される前に止める」ものではなく、「反映された変更を記録し、必要なら元に戻す」ためのツールです。

## 2. 使い始めるまでの準備

初回だけ、以下の3ステップが必要です。**特に2-2は必須**で、これを飛ばすとGASの登録も変更検知もできません。

### 2-1. ログインする

SavePointはブラウザからアクセスします。アクセス時にGoogleアカウントでのログインを求められるので、会社のGoogleアカウントでログインしてください。許可されていないアカウントの場合はアクセスできません（管理者に連絡してください）。

### 2-2. 自分のGoogleアカウントを接続する【必須】

ログインしただけでは、SavePointはまだあなたのGASを読み書きできません。**「ログイン」とは別に、「GASを操作する許可」をSavePointに与える操作が必要です。**

未接続の場合、ダッシュボードの上部に「**あなたのGoogleアカウントが未接続です**」という案内が出ます。

1. 「**Googleアカウントを接続する**」ボタンを押す
2. Googleの確認画面が出るので、ご自身の会社アカウントを選ぶ
3. 求められている許可の内容を確認して「許可」を押す

接続が完了すると、画面左下の「接続中のGoogleアカウント」にご自身のメールアドレスが表示されます。

> **なぜ必要か**: SavePointは「SavePointというシステムの権限」ではなく「あなた自身の権限」でGASを読み書きします。こうすることで、あなたが見られないGASをSavePoint経由で覗けてしまう、といったことが起きません。その代わり、一人ひとりが自分で接続する必要があります。

なお、**他の人が登録済みのGASを閲覧するだけなら接続は不要**です。自分でGASを登録したり、変更検知・セーブ・復元を行う場合に必要になります。

### 2-3. Google Apps Script API をオンにする【必須】

こちらもGoogleアカウントごとに1回だけ必要な設定です。

1. ご自身の会社アカウントで <https://script.google.com/home/usersettings> を開く
2. 「**Google Apps Script API**」を **オン** にする
3. 反映まで数分かかることがあります

この設定がオフのままだと、変更検知や復元の際に「Google Apps Script APIが有効になっていません」というメッセージが表示されます。

## 3. 権限について

SavePointの権限は2段階です。

| 権限 | できること |
|------|-----------|
| **管理者（admin）** | すべてのGASプロジェクトを操作可能。ユーザー管理・監査ログの閲覧・台帳への新規登録・台帳からの削除もできる |
| **メンバー（member）** | デフォルトではどのGASプロジェクトにもアクセスできない。GASプロジェクトごとに個別にアクセス権を付与された場合のみ、そのプロジェクトを操作できる |

メンバーがGASプロジェクトへアクセスするには、管理者が以下いずれかの役割を個別付与する必要があります（付与のしかたは §6-3）。

| プロジェクト内の役割 | できること |
|-------|-----------|
| 所有者（owner） | そのプロジェクトに関するすべての操作（メンバー管理を含む） |
| 保守担当（maintainer） | 所有者に近い操作。ただしメンバー管理はできない |
| 開発者（developer） | 変更の検知・セーブ・復元ができる |
| 閲覧者（viewer） | 状態・差分・履歴を見るだけ |

自分がどのプロジェクトにもアクセスできない場合、ダッシュボードには「アクセス権のあるGASプロジェクトがありません。管理者に台帳画面での個別付与を依頼してください。」と表示されます。この場合は管理者に付与を依頼してください。

## 4. 画面構成

左サイドバーから各画面に移動できます（ロゴ部分をクリックするといつでもダッシュボードに戻れます）。「監査ログ」「ユーザー管理」は管理者にのみ表示されます。

| 画面 | 用途 |
|------|------|
| ダッシュボード | 登録済みGASプロジェクトの一覧と、変更あり/変更なしの状態を確認する |
| 台帳 | GASプロジェクトの登録・編集・削除、プロジェクトごとのメンバー管理 |
| セーブ管理 | 未セーブの変更をセーブポイントとして記録する、過去のセーブポイントを一覧・復元する |
| 変更履歴 | 検知された変更を時系列で確認する（未セーブ／セーブ済み／復元により取消） |
| 監査ログ（管理者のみ） | 誰がいつ何を操作したかの記録 |
| ユーザー管理（管理者のみ） | SavePointにログインできる人と権限の管理、GASアクセス権の一括設定 |

台帳・ダッシュボードの各GASには「**GASを開く ↗**」リンクがあり、その場でGASエディタを別タブで開けます。

## 5. 日常の操作フロー

### 5-1. GASを編集する

いつも通りGASエディタで編集・保存してください。SavePoint側で何か操作する必要はありません。

### 5-2. 変更に気づく

- **自動**: 平日の9:00〜18:30、30分ごとに自動チェックが動きます。業務時間内に加えた変更は、おおむね30分以内に検知されます。
- **手動**: すぐに確認したい場合は、ダッシュボードの対象プロジェクトカードにある「変更を検知」ボタン、またはセーブ管理画面の「今すぐ変更を検知する」を押してください。

検知されると、そのプロジェクトのステータスが「変更あり」になり、変更履歴に記録されます。「差分を見る」で、何行追加・削除されたか、具体的にどの行が変わったかを確認できます。

### 5-3. セーブポイントを作成する（セーブする）

1. ダッシュボードのプロジェクトカード、または左メニューの「セーブ管理」から対象プロジェクトを選ぶ
2. 「今の状態をセーブする」画面で、未セーブの変更件数・追加/削除行数を確認する
3. 「セーブコメント」に、何のための変更かを短く書く（後から探しやすくなります）
4. 「セーブする」を押す

セーブすると、前回のセーブポイントからの変更内容についてAIが自動で影響レビューを作成します。**このレビューはあくまで参考情報です。内容の良し悪しに関わらずセーブ自体は必ず成功します**（レビューがAI障害等で作成できなかった場合も、セーブ自体は失敗しません。その場合はセーブポイントの詳細画面から「レビューを再生成する」を押してください）。

### 5-4. 過去のセーブポイントを確認する

「セーブ管理」→「セーブポイント一覧」から、過去のセーブポイントを新しい順に確認できます。各セーブポイントの詳細画面では、含まれる変更内容とAIレビューを確認できます。

なお、**台帳に登録した時点の状態が自動的に最初のセーブポイント（v1）として記録されます**。管理を始めた時点にはいつでも戻せます。

### 5-5. 過去の状態に戻す（ロールバック）

1. 戻したいセーブポイントの詳細画面を開く
2. 「このセーブポイントに復元」を押す
3. 確認ダイアログで復元先の内容を確認し、実行する

復元を実行すると、次の3つが自動的に行われます。

- **復元する直前のGASの状態が、新しいセーブポイントとして保存される**（コメントに「ロールバック前の自動バックアップ」と記載）
- 復元後の状態も、セーブポイントとして記録される
- 復元によって消えた未セーブの変更が、変更履歴上で「**復元により取消**」になる

つまり「復元をやり直したい」場合は、自動バックアップされたセーブポイントに再度復元すれば元に戻せます。データが失われることはありません。

復元ボタンには開発者（developer）以上の権限が必要です。

> **補足**: 誰かがGASエディタで編集した直後に復元を実行しようとすると、「ほかの人が変更しています」という主旨のメッセージが出て中断されます。知らないうちに他人の作業を消してしまわないための安全装置です。もう一度「変更を検知」してから、あらためて操作してください。

## 6. GASプロジェクトの登録・管理（管理者向け）

### 6-1. 新しいGASを登録する

「台帳」画面の「手動で登録（バインドGAS）」フォームに、GASエディタの「プロジェクトの設定」で確認できるスクリプトIDなどを入力し、「台帳に登録する」を押します。

すでに接続済みのGoogleドライブ内にある、まだ台帳未登録のスタンドアロンGAS（スプレッドシート等に紐付いていない単独のGAS）は、「検出を実行」から自動検出もできます。ただしスプレッドシートに紐付いたバインドGASは自動検出できないため、手動登録が必要です。

登録すると、以下が自動で行われます。

- 登録時点の状態が**最初のセーブポイント（v1）**として保存される
- AIがコードを読んで**READMEを自動生成**する（台帳の「README を見る」から確認できます）
- 「**用途**」欄が空欄の場合、AIが読み取った要約が自動で入る（自分で入力した内容が上書きされることはありません）

**同じGASを二重に登録することはできません**。すでに登録済みのスクリプトIDを登録しようとすると、その旨のメッセージが出て拒否されます（登録ボタンを続けて押してしまった場合も、登録されるのは1件だけです）。

### 6-2. 用途・担当部署を編集する

台帳の各行から、プロジェクト名・用途・担当部署・状態を編集できます。スクリプトIDは登録後に変更できません（別のGASとして登録し直してください）。

### 6-3. メンバーにアクセス権を付与する

付与のしかたは3通りあります。人数とGASの数に応じて使い分けてください。

**(a) 1つのGASに、1人ずつ付与する**

台帳の対象プロジェクト行にある「メンバー」を押すと、メンバー管理パネルが開きます。**登録済みユーザーの一覧から選ぶ形式**なので、メールアドレスを手で入力する必要はありません。役割（所有者/保守担当/開発者/閲覧者）を選んで「追加」を押してください。

候補に出てこない方は、先に「ユーザー管理」画面で登録してください（§7）。

**(b) 複数のGASに、1人をまとめて付与する**

台帳の一覧で、対象GASの左端にあるチェックボックスを複数選びます。上部に「〇件選択中」というバーが出るので、付与したい**利用者**と**役割**を選んで「**まとめて付与**」を押します。

**(c) 1人に対して、触れるGASをまとめて設定する**

「ユーザー管理」画面で対象の方の「**GASアクセス権**」を押すと、登録済み全GASの一覧が出ます。GASごとに役割を選び（外す場合は「アクセスなし」）、「保存」を押すと一括で反映されます。

「この人は結局どのGASを触れるのか」を確認したいときにも、この画面が便利です。

なお、管理者は個別付与なしで常に全プロジェクトへアクセスできます。上記の設定は主にメンバー権限の方に対して行うものです。

### 6-4. 管理をやめる（台帳から削除する）

GAS自体が廃止された場合や、誤って登録した場合は、台帳の対象行から「削除」を押します。

- **削除されるもの**: 台帳の登録情報・セーブポイント・変更履歴・メンバー権限
- **削除されないもの**: **GAS本体**（Google側のGASは一切変更されません）、監査ログ（誰が何をしたかの記録は残ります）

削除は元に戻せません。確認ダイアログで内容をよく確認してください。削除後、同じGASをあらためて登録し直すことは可能です。

> **「まだ使うが、当面さわらない」場合**: 削除ではなく、台帳の「状態」を変更する運用をおすすめします。履歴を残したまま管理対象から外せます。

## 7. ユーザー管理（管理者向け）

「ユーザー管理」画面から、SavePointにログインできる人とその権限（管理者/メンバー）を登録・変更・削除できます。

新しく利用を始める人の登録手順は次の通りです。

1. 「ユーザー管理」画面でメールアドレスを入力し、「メンバー」として登録する
2. 登録すると、**その方へ招待メールが自動送信されます**（送信元は操作した管理者自身のGoogleアカウント）
3. 必要なGASへのアクセス権を付与する（§6-3）
4. 本人に、初回の準備（§2-2 のアカウント接続と §2-3 のAPI設定）を案内する

招待メールが届かなかった場合は、ユーザー管理画面から再送できます。

## 8. よくある質問・トラブルシューティング

**Q. ダッシュボードに「あなたのGoogleアカウントが未接続です」と出る**
A. 初回の接続がまだです。§2-2 の手順で「Googleアカウントを接続する」を実行してください。ログインとは別の操作です。

**Q. 「Google Apps Script APIが有効になっていません」と表示される**
A. §2-3 の設定がまだです。ご自身のアカウントで <https://script.google.com/home/usersettings> を開き、「Google Apps Script API」をオンにしてください。反映に数分かかることがあります。

**Q. ダッシュボードで「アクセス権のあるGASプロジェクトがありません」と表示される**
A. あなたのアカウントがどのGASプロジェクトにもメンバー登録されていません。管理者に、対象プロジェクトへの個別付与を依頼してください。

**Q. 「変更を検知」「セーブする」ボタンが押せない（グレーアウトしている）**
A. そのプロジェクトでの自分の権限が「閲覧者」になっている可能性があります。操作が必要な場合は管理者に「開発者」以上への変更を依頼してください。

**Q. メンバー追加の候補に、追加したい人が出てこない**
A. その方がまだSavePointのユーザーとして登録されていません。先に「ユーザー管理」画面で登録してください（§7）。

**Q. セーブしたのにAIレビューが表示されない**
A. AIレビューの生成に一時的に失敗した状態です。セーブ自体は完了しているので、セーブポイントの詳細画面を開き「レビューを再生成する」を押してください。それでも失敗する場合は開発担当へ連絡してください。

**Q. 「認証エラー」と表示されてGASの状態を取得できない**
A. GAS本体へアクセスするための接続が期限切れになっている可能性があります。§2-2 の手順でもう一度接続し直してください。それでも解消しない場合は開発担当へ連絡してください。

**Q. 復元（ロールバック）を間違えてしまった**
A. 復元の直前の状態は自動的にセーブポイントとして保存されています。「セーブポイント一覧」からその自動保存分（コメントに「ロールバック前の自動バックアップ」と記載）を探し、そこへ再度復元してください。

**Q. 復元しようとしたら「ほかの人が変更しています」と出て実行できない**
A. 画面を開いてから今までの間に、誰かがGASを編集した可能性があります。他人の作業を知らずに消してしまわないための安全装置です。「変更を検知」で最新の状態を取り込み、差分を確認してからあらためて操作してください。

**Q. 変更履歴に「復元により取消」と出ている**
A. その変更は、その後の復元操作によって取り消されたという意味です。対応が必要な未セーブの変更ではありません。

**Q. 同じGASを登録しようとしたら拒否された**
A. すでに台帳に登録済みです。台帳の一覧で名前やスクリプトIDを検索して確認してください。

**Q. 自動チェックは何時に動いていますか**
A. 平日の9:00〜18:30に、30分ごとに動きます。夜間・休日は動きません。すぐ確認したい場合は手動の「変更を検知」を使ってください。

## 9. 用語集

| 用語 | 説明 |
|------|------|
| セーブポイント | ある時点のGASソースコード全体のスナップショット |
| 変更検知 | 前回の記録と現在のGASの内容を比較し、差分があるかどうかを確認する処理 |
| 未セーブの変更 | 検知はされたが、まだセーブポイントとして記録されていない変更 |
| セーブ済み | セーブポイントとして記録が完了した変更 |
| 復元により取消 | 検知された後に復元（ロールバック）が行われ、GAS上には残っていない変更。対応不要 |
| ロールバック | 過去のセーブポイントの内容でGAS本体を上書きし、その時点の状態に戻すこと |
| 自動バックアップ | 復元の直前の状態を自動保存したセーブポイント。復元のやり直しに使う |
| AIレビュー | セーブ時にAIが自動生成する、変更内容・想定される影響・確認しておくとよい点のまとめ。参考情報であり、セーブの可否には影響しない |
| アカウント接続 | SavePointに、自分の権限でGASを読み書きする許可を与えること。ログインとは別の操作（§2-2） |
| スクリプトID | GASを一意に識別するID。GASエディタの「プロジェクトの設定」で確認できる |
